## Intentional reference corrections

- The API has one total coupon usage limit, with no per-customer limit. That unsupported field is omitted.
- The API allows editing a used coupon's code and discount. The screenshot's additional locks are not imposed as new business rules. The real used flash-sale product/unit lock and used-count/quantity lower bounds remain enforced.
- Product quantity limits are overall promotion quantities, including supported fractional units; they are not labeled as per-customer purchase limits.
- Per the October 17 request, schedule inputs are date-only for coupons and flash sales. Clicking the field invokes the native calendar when supported, with native date entry as fallback. Selecting a date sends business-local `T00:00` at the API's required minute precision; the backend supplies zero seconds, so the stored local time is `00:00:00`. Clearing sends null. The business timezone stays informational and empty dates remain unrestricted. Existing saved non-midnight schedules retain their time when other fields are edited; selecting a new date replaces that boundary with midnight.
- Conflicts depend on the selected availability window. Following the October 18 request, the picker asks the publications API for schedule-specific flash-sale availability. Rows assigned to overlapping enabled flash sales are disabled with the event name; bulk selection skips them. Adjacent/non-overlapping schedules, paused/deleted events and the current event being edited do not block selection. A disabled draft event follows the existing API rule allowing it to share products. Add rechecks selected IDs across all search/pages and removes newly unavailable selections with an explicit notice. The backend still checks overlaps atomically on Save to protect against later races. Deploy the updated Laravel publications controller with the mobile UI; older APIs cannot provide these availability annotations.
- Paused/exhausted/all states, category filtering, bulk filtered product selection, promotion names and optional minimum subtotal remain available even where the references omit them. These preserve existing supported behavior.
- Form controls follow shared compact heights, typography and radius tokens. Real content scrolls instead of compressing every field into one frame. Narrow date controls stack; Myanmar text wraps. Native status chrome, actual currencies/dates/records and missing-photo package fallbacks differ from the illustrative records.
