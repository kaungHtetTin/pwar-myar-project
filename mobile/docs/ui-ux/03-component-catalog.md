Repeated names in different files are different implementation owners. Inputs below are source signatures, not new APIs. Preserve callbacks, payloads, refs, validation and lifecycle when restyling.

## Shared state and variant contract

For each applicable component design: default, focused, pressed/selected, disabled/read-only, busy, empty, error/retry and success. Data containers additionally need first-load, background refresh, loaded, load-more, end-of-list, stale/unavailable and permission-restricted variants. Do not manufacture irrelevant states for nonvisual wrappers. All visual components inherit [tokens, touch targets, type, accessibility and responsiveness](01-design-system.md).

Each file table supplies an implementation owner, inputs and a component-specific target contract. See the owning module in the screen specifications for its full layout and business constraints. The inventory records source lines at generation time; regenerate after code changes.

## Inline elements and composed visual primitives

These are also design components even when implemented directly in a page rather than as named React functions. They must appear in the design file/component library.

| Element family | Required variants / contract |
| --- | --- |
| Page headings and Back | Index/detail/form; long title; source-aware return; one page heading. |
| Toolbar and search | Empty/filled/focused/cleared/searching; consistent search/filter/export order and no overflow. |
| Button/icon button/action tile | Primary/secondary/destructive; icon+label; disabled/busy; 44px targets; long Myanmar label. |
| Input/textarea/select | Required/optional; help/error; focused/disabled/read-only; number/currency/password/date; keyboard-safe. |
| Checkbox/radio/switch | Off/on/disabled; labeled consequence; preserve native semantics. |
| Tabs/step progress | Active/inactive/completed/unavailable; correct accessible state; retain previous-step data. |
| Status badge/stock label | Order/payment/stock/subscription/block/unread; text and color; wrapping without clipped values. |
| Avatar/initials/image fallback | Loaded/missing/broken; customer vs product; profile click target only where supported. |
| Contact/record rows | Long/missing contact; receivable/payable/settled or purchase summary; separate trailing menu. |
| Monetary summary/metric | Zero/negative/large/loading/unavailable; currency and scope label; do not mix currencies. |
| Item line/quantity controls | Price/unit conversion/FOC/stock warning/remove; labeled inputs and accurate total. |
| Date/range/preset | Selected/custom/invalid/required; inside drawer; preserve timezone/defaults. |
| Notice/toast/inline error | Info/success/warning/error; dismissal/retry when supported; appropriate announcement. |
| Modal/sheet/drawer | Title/context/close; short/long body; fixed actions; focus restoration, backdrop and Back. |
| Skeleton/spinner/progress | Match loaded geometry; initial/local/pagination/refresh; reduced motion; one concise status. |
| Empty/no-results/not-found/gate | Distinct reason and useful recovery; no unauthorized data flash. |
| Chart/rank/table | Zero/one/many/large values; period/currency context; readable alternate values; contained overflow. |
| Chat bubble/date/time/delivery | Incoming/outgoing, multiline/media/product; sending/failed/retry/expired/read-only; no invented server state. |
| Upload/camera/crop/preview | Existing/pending/replace/remove/denied/invalid/busy; stop camera and release temporary resources on exit. |
| Receipt/barcode/print status | Paper/physical sizing, preview/loading/failure; print attempt separate from transaction mutation. |
| Selection/bulk toolbar | None/some/max; select loaded vs matching; persisted selection; scope-aware confirmation. |
| Audit/expandable section | Collapsed/expanded/loading/empty; chronological context; pending decisions not hidden by decoration. |
| Navigation menu/module row/banner | Authorized/active/denied/subscription/offline; proper source navigation and account isolation. |

## Nonvisual contracts outside JSX component inventory

Review `src/navigation/historyNavigation.js`, retained-view/page-activity/page-refresh utilities, `src/hooks/useEndlessList.js`, `src/api/client.js`, `src/offline`, chat activity/realtime helpers, localization dictionaries and `src/utils` printing/export code before changing a related flow. These are behavior dependencies, not decorative components. Use current file names in those directories when implementing; do not relocate or replace them merely to restyle a screen.

Current visual owners include global `src/styles/index.css`, module styles, and shop refinements: `filter-drawer.css`, `order-detail.css`, `shop-customer-detail.css`, `shop-customers.css`, `shop-loading.css`, `shop-chat.css`, and `shop-reviews.css`. Keep cascade/import ordering in mind. Prefer shared semantic classes/tokens over increasingly specific duplicate overrides.
