## Visual rules
### Mandatory reference acceptance for all future UI work
Treat each mapped reference screenshot as the visual acceptance target. Compare the rendered page side by side at the same viewport. Check exact labels, font size and weight, line breaks, spacing, borders, focus states, and button placement. Fix visible differences before reporting completion. Tests prove behavior, not visual fidelity. Identify any unavoidable difference explicitly; never claim a match without inspecting the final screenshot.
